# hcp_resource_control_policy (Resource)

Manages the organization-level resource control policy constraints for an HCP organization. Enabled constraints define restrictions applied to resources within the organization.

Use this resource to manage organization-wide resource creation guardrails in HCP. By enabling constraints, you can prevent specific HCP resource types from being created in the organization.

## Example Usage

```terraform
data "hcp_organization" "example" {}

resource "hcp_resource_control_policy" "example" {
  organization_id = data.hcp_organization.example.resource_id

  enabled_constraints = [
    "constraints/packer.deny-creation",
    "constraints/vault.deny-creation",
  ]
}
```

## Import

Import is supported using the following syntax:

```shell
# Resource control policy can be imported by specifying the organization ID
terraform import hcp_resource_control_policy.example "organization-id"
```
